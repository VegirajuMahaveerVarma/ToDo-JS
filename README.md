# TaskFlow — by Maha

A premium, mobile-first To-Do / productivity app built with React and JavaScript.

## Features

- Premium glassmorphism-inspired mobile UI
- Today, Upcoming and Done views
- Search and category filtering
- Add, complete and delete tasks
- Priority and category tags
- Progress ring and productivity stats
- Dark / light theme
- LocalStorage persistence
- Responsive mobile-first layout
- Designed & developed by Maha

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL in your browser. The app is designed to work especially well on Android mobile browsers.
